# Resources

> A curated collection of supplementary materials beyond what's in the weekly curriculum. Quality over quantity — every link here has been vetted. Add to this as you discover good things.

---

## 📚 Documentation (Bookmark These Forever)

- [MDN Web Docs](https://developer.mozilla.org/) — The single most important reference site for web developers. Use it for HTML, CSS, JavaScript, and Web APIs.
- [React Docs](https://react.dev/) — The official React documentation, rewritten in 2023. Excellent.
- [JavaScript.info](https://javascript.info/) — A complete, free JavaScript book. Read alongside the curriculum.
- [Can I Use](https://caniuse.com/) — Check browser support for any web feature.
- [DevDocs](https://devdocs.io/) — Offline access to almost every dev documentation set.

## 🎥 YouTube Channels Worth Subscribing To

- [Kevin Powell](https://www.youtube.com/@KevinPowell) — The CSS GOAT. Watch anything he posts.
- [Web Dev Simplified](https://www.youtube.com/@WebDevSimplified) — Clear, short tutorials on JS and React.
- [Fireship](https://www.youtube.com/@Fireship) — Punchy "X in 100 seconds" overviews. Good for getting the gist of new tech fast.
- [Theo - t3.gg](https://www.youtube.com/@t3dotgg) — Industry takes on modern frontend trends. Watch later, after fundamentals.
- [Josh tried coding](https://www.youtube.com/@joshtriedcoding) — Practical project tutorials.
- [Jack Herrington](https://www.youtube.com/@jherr) — Deep dives on React patterns.

## 🎨 Design & UI Resources

- [Refactoring UI](https://www.refactoringui.com/) — A short, life-changing book on design for developers. There's a paid book but the free articles and videos are also great.
- [Tailwind UI Components](https://tailwindcss.com/plus/ui-blocks) — See well-built modern components (preview is free).
- [Hero Patterns](https://heropatterns.com/) — Free SVG background patterns.
- [Coolors](https://coolors.co/) — Color palette generator.
- [Google Fonts](https://fonts.google.com/) — Free, well-licensed fonts.
- [Heroicons](https://heroicons.com/) and [Lucide](https://lucide.dev/) — Free icon libraries.
- [Unsplash](https://unsplash.com/) and [Pexels](https://www.pexels.com/) — Free stock photos.
- [unDraw](https://undraw.co/) — Free customizable illustrations.

## 🛠️ Tools & Utilities

## 🌐 Free APIs to Build With

When you need an API for a project, pick one of these. All are free, most need a key.

- [Open-Meteo](https://open-meteo.com/) — Weather, no API key required. Perfect for the Week 7 project.
- [The Movie DB (TMDB)](https://www.themoviedb.org/documentation/api) — Movies and TV. Used in Week 10.
- [PokéAPI](https://pokeapi.co/) — All things Pokémon, no auth.
- [Spoonacular](https://spoonacular.com/food-api) — Recipes and nutrition.
- [The Cocktail DB](https://www.thecocktaildb.com/api.php) — Drink recipes.
- [Rest Countries](https://restcountries.com/) — Country data.
- [News API](https://newsapi.org/) — Headlines from around the world.
- [Public APIs list](https://github.com/public-apis/public-apis) — A massive curated index of free APIs.

## 📖 Articles & Posts Worth Reading

### Career
- [Patrick McKenzie — Don't Call Yourself a Programmer](https://www.kalzumeus.com/2011/10/28/dont-call-yourself-a-programmer/) — Older but still relevant career advice.
- [Julia Evans — How to ask good questions](https://jvns.ca/blog/good-questions/)
- [Matt Might — 12 resolutions for programmers](https://matt.might.net/articles/programmers-resolutions/)

### Web Fundamentals
- [How browsers work](https://web.dev/articles/howbrowserswork) — A long but worthwhile read.
- [What forces layout / reflow](https://gist.github.com/paulirish/5d52fb081b3570c81e3a) — Performance gold.

### CSS
- [The CSS Cascade visualized](https://wattenberger.com/blog/css-cascade)
- [Every Layout](https://every-layout.dev/) — A new way to think about layout primitives.
- [Modern CSS Solutions](https://moderncss.dev/) — Stephanie Eckles' series on solving common problems with modern CSS.

### JavaScript
- [You Don't Know JS (book series, free on GitHub)](https://github.com/getify/You-Dont-Know-JS) — Deep JS knowledge. Read this in Year 2.
- [JavaScript Visualized series by Lydia Hallie](https://www.lydiahallie.com/blog) — The event loop, prototypes, and more, with diagrams.

### React
- [React Patterns at Patterns.dev](https://www.patterns.dev/react/)
- [Josh W Comeau's blog](https://www.joshwcomeau.com/) — Some of the best React explainers anywhere.

## 🧠 When You're Ready to Go Deeper (Post-Curriculum)

These are intentionally NOT for during the 12 weeks — they're what to explore next.

- **TypeScript:** [TS Handbook](https://www.typescriptlang.org/docs/handbook/intro.html), [Total TypeScript](https://www.totaltypescript.com/) (paid courses, free articles)
- **Testing:** [Testing Library docs](https://testing-library.com/), [Kent C. Dodds blog](https://kentcdodds.com/blog)
- **Next.js:** [Next.js Learn course](https://nextjs.org/learn) (official, free)
- **Animation:** [Motion (formerly Framer Motion)](https://motion.dev/), [GSAP](https://gsap.com/)
- **State management:** [Zustand](https://zustand-demo.pmnd.rs/), [TanStack Query](https://tanstack.com/query) (game-changer for API data)
- **Backend basics:** [The Odin Project — NodeJS](https://www.theodinproject.com/paths/full-stack-javascript/courses/nodejs)
